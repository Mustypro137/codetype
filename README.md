# CodeType

A typing practice web app for programmers. Instead of normal sentences, you type real code snippets and see your speed and accuracy.

## Plan
1. Choose a programming language (for example JavaScript, Python, HTML, CSS).
2. Get a real code snippet in that language.
3. Type the snippet. Correct and wrong characters are shown in different colors.
4. See live speed (WPM – words per minute) and accuracy.
5. See a results screen at the end, and try again.

## Tech
Plain HTML, CSS and JavaScript. No frameworks, no build tools. Hosted on GitHub Pages.

## Folder structure
```
index.html           main page
css/style.css        styles
js/                  JavaScript, split into small files
data/                code snippets
images/              images and icons
CONTRIBUTION-LOG.md  what I did, what AI did, what I learned
```

## How to run
Open `index.html` in a browser. Later, it will be online with GitHub Pages.
